# Interface do funcionário

A tela `html/tela_alerta.html` foi substituída por um painel com a mesma linguagem visual do painel administrativo: menu lateral escuro, cabeçalho, cards, tabelas, painéis e navegação por seções.

O funcionário continua limitado ao seu perfil. O painel não exibe cadastro de usuários nem configurações administrativas.

Seções disponíveis:
- Dashboard
- Estoque Central
- Prateleiras
- Movimentações
- Alertas
- Perfil

A sessão PHP continua sendo a autoridade de acesso.
